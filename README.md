## 🚀 Overview

**ConvertHub v2** is a state-of-the-art, fully offline desktop workstation designed for high-speed file conversion, custom archiving, and advanced visual PDF management. 

By integrating industry-standard local engines—**FFmpeg**, **LibreOffice**, and **7-Zip**—directly into a beautifully crafted, modern Electron interface, ConvertHub v2 delivers maximum performance without compromising privacy. **Your files never touch the cloud.**

### 💎 Key Highlights
- **100% Offline & Private:** No servers, no tracking, and no external dependencies.
- **Parallel Processing:** Multi-threaded queue system for lightning-fast batch conversions.
- **GPU Acceleration:** Harness your hardware for media encoding speedups.
- **Visual PDF Workspace:** Drag, rotate, delete, and structure document pages interactively.

## 🔥 Features & Capabilities

### 🔀 Universal File Converter
- 🎵 **Audio Engine:** Convert between `MP3`, `WAV`, `AAC`, and `FLAC` with precision bitrate control.
- 🎬 **Video Engine:** Rapid processing of `MP4`, `MKV`, `MOV`, and `AVI` container formats.
- 🖼 **Image Studio:** Streamlined conversion for web formats including `JPG`, `PNG`, and `WEBP`.
- 📄 **Document Suite:** High-fidelity offline conversions powered by an embedded LibreOffice environment.
- 📦 **Archive Control:** Create high-efficiency compressed packages (`ZIP` & `7Z`) leveraging 7-Zip.
- ⚡ **Batch Processing:** Parallel queue pipeline manages massive batch actions smoothly.
- ⚙️ **GPU-Accelerated:** Automatic detection and integration of hardware encoders.

### 📷 Smart Image Toolkit
- 📐 **Resize & Crop Studio:** Scale proportionally, crop visually, or fit to specific dimensions (`cover`, `contain` with color bounds, `fill`) with interactive preset profiles.
- 🔄 **Orientation & Transforms:** Flip images horizontally/vertically or rotate in 90° intervals.
- 📉 **Optimized Compressors:** Re-encode to `JPEG`, `PNG`, `WebP`, or `AVIF` formats while estimating and previewing file size savings.
- ✍️ **Visual Watermarker:** Draw custom brand logos or styled text (fonts, size, color picker, opacity, rotation, tiling layouts) with a live canvas preview.

### 📐 Smart PDF Toolkit
- 🖼 **Image to PDF Compiler:** Compile lists of images into structured PDFs with custom layouts, margins, rotation, backgrounds, titles, and password encryption.
- 🔗 **Interactive PDF Merger:** Combine multiple PDF documents or select targeted page ranges.
- ✂️ **Visual Page Organizer:** Drag-and-drop environment to interactively re-order, rotate, delete, or extract pages.
- 📂 **Visual PDF to Images:** Render preview thumbnails of PDF pages, visually select/deselect pages with sync checkboxes, and extract to images or compile to image ZIPs.
- 📉 **Advanced PDF Compression:** Pure lossless Flate compression or lossy re-encoding for significant size reduction.
- ✍️ **Custom Watermarker:** Brand documents with adjustable text, font size, placement, color opacity, and rotation.

## 🛠 Tech Stack

ConvertHub v2 brings together powerful, open-source technologies in a unified workspace:

- **Electron** – High-performance desktop application shell.
- **Node.js** – Backend runtime and pipeline orchestration.
- **pdf-lib & pdfjs-dist** – Advanced PDF rendering, editing, and client-side compilation.
- **FFmpeg** – Industry-standard audio/video processing suite.
- **LibreOffice** – Enterprise-grade offline document rendering engine.
- **7-Zip** – High-ratio file compression and extraction library.

## 💡 Important Notes

- **OS Support:** Optimized natively for Windows systems.
- **Security Check:** All conversion engines execute **locally on your machine**. Antivirus programs may occasionally trigger false-positive alerts on bundled binaries due to local execution.
- **Hardware Benefits:** Conversion queues and media encoders scale dynamically based on your CPU threads and GPU capabilities.
