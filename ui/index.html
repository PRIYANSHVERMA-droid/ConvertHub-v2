About

About ConvertHub

v2.2.1

ConvertHub v2 is a premium desktop conversion workspace designed to run entirely offline on your local machine. It provides high-performance batch conversions across audio, video, image, document, and archive formats using fine-tuned conversion configurations.

The integrated Smart PDF Toolkit enables compiling images into PDFs, merging multiple PDF files, extracting high-resolution page assets, enforcing optional password encryption, and customizing layout orientation, margins, and paper sizes.

The brand-new Smart Image Toolkit features dynamic, canvas-driven pipelines for resizing, cropping, flipping, and rotating, alongside custom-tuned compression and multi-placement text or logo watermarks with real-time feedback.

Engine Setup Required

One or more conversion engines are missing on your system. Follow the steps below to install them.

LibreOffice Document Conversions

LibreOffice is required for converting between document formats (DOCX, PDF, ODT, XLSX, PPTX, etc.).

Install via Homebrew (Recommended)
brew install --cask libreoffice
Download installer directly

After installation, restart ConvertHub. LibreOffice will be detected automatically from /Applications/LibreOffice.app.

LibreOffice Document Conversions

LibreOffice is required for converting between document formats (DOCX, PDF, ODT, XLSX, PPTX, etc.).

Ubuntu / Debian
sudo apt install libreoffice
Fedora / RHEL
sudo dnf install libreoffice
Arch Linux
sudo pacman -S libreoffice-fresh
Download installer directly

After installation, restart ConvertHub. LibreOffice will be detected automatically from /usr/bin/soffice.

Windows

All conversion engines are pre-bundled with the Windows installer. No additional setup is needed.

If you see an engine marked as "missing" on Windows, try reinstalling ConvertHub from the official release page.
