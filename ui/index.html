About

About ConvertHub

v1.0.0

ConvertHub v2 is a premium desktop conversion workspace designed to run entirely offline on your local machine. It provides high-performance batch conversions across audio, video, image, document, and archive formats using fine-tuned conversion configurations.

The integrated Smart PDF Toolkit enables compiling images into PDFs, merging multiple PDF files, extracting high-resolution page assets, enforcing optional password encryption, and customizing layout orientation, margins, and paper sizes.
